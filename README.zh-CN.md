## ✨ 功能亮点

| | |
|---|---|
| 🧾 **文本自动打码** | 手机号、身份证、银行卡、姓名……页面一加载即自动隐藏，只保留首尾字符，中间灰底遮罩。 |
| 🖱️ **悬停查看原文** | 鼠标移到遮罩上，临时显示原始内容 —— 酷炫又实用。 |
| 🖼️ **图片 OCR 打码** | 图片*里面*的文字也会被本地识别（WASM OCR）并打码 —— 合同扫描件也漏不了。 |
| 🎯 **按站点开关** | 工具栏一键「应用于当前网页」/取消，按域名记住，下次访问自动生效。 |
| 🌐 **中英双语界面** | 配置页全量中英切换，随时可换。 |
| 🔁 **JSON 导入导出** | URL 与规则以 JSON 呈现：可查看、编辑、导入文件、复制 —— 多台设备配置随身带。 |
| 🔒 **100% 本地运行** | OCR 模型内置、页面内 WebAssembly 推理，数据不出浏览器。 |

## 🚀 安装（开发者模式加载）

1. 打开 Chrome / Edge / Brave（Chromium 内核）的 `chrome://extensions`。
2. 右上角开启**开发者模式**。
3. 点**加载已解压的扩展程序**，选择 `mask-your-web` 目录（含 `manifest.json` 的那个文件夹）。
4. 把 🕶️ 图标固定到工具栏。

无需构建、无依赖、无服务器。

## 🧑‍💻 使用

### 工具栏弹窗

任意页面点击扩展图标：

- **应用于当前网页** —— 把当前域名加入候选集并自动刷新，立即生效；再点一次取消。
- **配置** —— 打开完整配置页。

### 配置页

- **启用脱敏** —— 总开关。
- **图片 OCR 打码** —— 关闭后只脱敏文本（省去加载 OCR 模型）。
- **URL 候选集** —— 每行一个。`example.com` 命中整个站点；`example.com/admin` 命中该路径及其子路径（`/admin`、`/admin/users`）。忽略 `www.` 前缀和大小写，http/https 均可命中。
- **脱敏规则** —— 每条规则 = 一个作用域 + 若干识别规则：

| 作用域 | 含义 |
|---|---|
| 全文 | 页面正文 + 表格文字 + 图片 OCR |
| 列名（整列） | 表头命中 → 整列打码 |
| 列值 | 只扫描表格单元格内容 |

识别规则分 **正则**（表达式）与 **词典**（每行一个词），每条可配「保留前 N / 后 N」。两者之和 ≥ 命中文本长度时等于不遮罩。

规则示例：

```json
{
  "enabled": true,
  "ocrEnabled": true,
  "urls": ["example.com", "admin.example.com/login"],
  "rules": [
    {
      "name": "个人信息",
      "scope": "full",
      "recognizers": [
        { "type": "regex", "pattern": "1[3-9]\\d{9}", "keepFirst": 3, "keepLast": 4 },
        { "type": "dict", "items": ["内部", "机密"], "keepFirst": 0, "keepLast": 0 }
      ]
    }
  ]
}
```

### JSON 配置

配置页底部整份配置（URL + 规则 + 开关）以 JSON 呈现：编辑 JSON 时上方表单实时联动；也可**导入文件** / **复制**，在多台机器间迁移配置。存一份 JSON 到你的仓库当备份也不错！

## 🔍 工作原理

- content script 先匹配候选集，命中后才注入轻量引擎。
- **文本**：扫描文本节点命中规则后，用覆盖层遮住中间（保留前 N / 后 N）。不改动页面 DOM 结构，悬停显原文即时生效，React/SPA 页面不崩。
- **图片**：内置 PaddleOCR（编译为 WebAssembly，约 9.6 MB）完全在标签页内推理；识别出命中规则的文字后直接把原图重绘打码（`***`）。

## 🛡️ 隐私

一切都在浏览器本地完成 —— OCR 推理、规则匹配、打码绘制。无统计、无网络上报（除扩展自身按需抓取你要打码的图片外）、无账号。

## 📁 目录结构

```
mask-your-web/
├── manifest.json          # MV3 manifest（_locales 中英双语名称/描述）
├── background.js          # service worker：引擎注入 + 跨域取图
├── content/               # content-script、OCR 运行时/模型、文本脱敏引擎
├── popup/                 # 工具栏卡片（应用于当前网页 + 配置入口）
├── options/               # 完整配置页（规则、候选集、JSON）
├── shared/i18n.js         # 中英词典
├── assets/                # 图标
├── _locales/              # 扩展商店中英名称与描述
├── demo-zh.gif            # 演示录屏（中文页面）
└── demo-en.gif            # 演示录屏（英文页面）
```
